# Vision Chat — локальный чат с картинками на телефоне

Приложение на Android: запускает на телефоне модель Qwen3-VL (abliterated) через llama.cpp (библиотека llama.rn).
Всё работает офлайн. Интернет нужен один раз, чтобы скачать модель.

## Как получить APK (≈ 20 минут, один раз)

Сборка идёт бесплатно на серверах GitHub, ничего ставить на компьютер не нужно.

1. Зарегистрируйся на github.com и создай новый репозиторий (можно приватный).
2. Загрузи в него **все файлы из этого архива**, включая скрытую папку `.github`
   (проще с компьютера: распакуй архив, на странице репозитория «Add file → Upload files», перетащи содержимое).
3. Открой вкладку **Actions** → слева **Build APK** → кнопка **Run workflow**.
4. Через 15–25 минут сборка станет зелёной. Открой её и внизу, в разделе **Artifacts**, скачай `vision-chat-apk`.
5. Распакуй zip, перекинь `.apk` на телефон и установи (разреши установку из неизвестных источников).

## Первый запуск

1. В приложении нажми «Скачать» у модели (для 12 ГБ RAM подойдут обе; сначала можно взять 4B, она быстрее).
   Скачивание большое (3–6 ГБ), держи Wi-Fi и не сворачивай приложение.
   Если загрузка оборвётся или нажмёшь паузу, просто нажми «Скачать» ещё раз: она продолжится с того же места.
2. Нажми «Запустить чат». Первая загрузка модели занимает до минуты.
3. Прикрепляй фото кнопками 📷 / 🖼 и пиши вопрос.

## Что важно знать

- GPU-ускорение в llama.rn на Android есть только для Qualcomm. На Dimensity работает процессор,
  поэтому скорость скромная (прикидка: единицы токенов в секунду на 8B, заметно быстрее на 4B).
  Если медленно, возьми 4B, уменьши «токенов на картинку» в настройках (⚙) или размер контекста.
- Свои модели: в разделе скачивания можно вставить ссылки на любой GGUF + mmproj с Hugging Face
  или выбрать файл из памяти телефона. Модель и mmproj должны быть от одной и той же архитектуры.
- Проект не тестировался на реальном телефоне. Если сборка или запуск упадут, пришли текст ошибки.
