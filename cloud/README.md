# Облачный сервер для Vision Chat (бесплатно, Kaggle / Colab)

Вместо медленной локальной модели на телефоне приложение может обращаться к вашему
собственному серверу в облаке с GPU. Сервер даёт OpenAI-совместимый API:

- чат с картинками (Qwen3-VL abliterated, GGUF через llama.cpp), потоковый ответ (SSE);
- генерация картинок (SDXL 1.0, diffusers);
- защита ключом (Bearer API key).

> **Что не проверено.** Код и ноутбуки написаны и проверены только статически
> (синтаксис Python, валидность JSON). На реальном GPU они ещё НЕ запускались:
> сборка llama.cpp, имена файлов моделей на Hugging Face, скорость и расход памяти
> нужно проверить при первом запуске. Если что-то упало, пришлите текст ошибки.

## Файлы

- `server.py` – сервер (FastAPI). Запускается одной командой.
- `kaggle_server.ipynb` – ноутбук для Kaggle (основной вариант, 2x T4 или P100).
- `colab_server.ipynb` – ноутбук для Google Colab (запасной, 1x T4).
- `requirements.txt` – зависимости Python (ставятся ноутбуком).

## Вариант 1: Kaggle (рекомендуется)

Бесплатная квота GPU около 30 часов в неделю (точное число смотрите в профиле Kaggle).

1. Зарегистрируйтесь на kaggle.com и **подтвердите номер телефона**
   (Settings -> Phone verification). Без этого GPU и Internet недоступны.
2. Создайте ноутбук: Create -> New Notebook.
3. Импорт файла: File -> Import Notebook -> вкладка **Link** (или GitHub) и вставьте:

   `https://raw.githubusercontent.com/houlashdw/Iaa/main/cloud/kaggle_server.ipynb`

   Если ссылка не принимается, скачайте файл на телефон и загрузите через вкладку Upload.
4. В настройках сессии (Session options / боковая панель справа):
   - **Accelerator: GPU T4 x2** (или GPU P100);
   - **Internet: On**.
5. (По желанию) Add-ons -> Secrets: создайте `API_KEY` (свой постоянный пароль, чтобы
   не менять его в приложении) и `NGROK_TOKEN` (запасной туннель, бесплатный токен с ngrok.com).
6. Нажмите Run All. Первый запуск: ~10-15 мин сборка llama.cpp и загрузка ~15 ГБ моделей.
   Дальше запуск в новой сессии снова занимает это время (кэш не сохраняется между сессиями).
7. Последняя ячейка напечатает **SERVER URL** (вида `https://xxxx.trycloudflare.com`) и **API KEY**.
   Скопируйте оба значения в настройки приложения (облачный режим). Ячейку не останавливайте.
8. Закончили – остановите сессию (Session options -> Stop), иначе тратится квота.

Советы: URL меняется при каждом запуске. Сессия живёт не больше ~9 часов; Kaggle
останавливает простаивающие сессии, держите вкладку открытой (на телефоне включите
«Версия для ПК» и не давайте экрану гаснуть). Режим Save Version -> Save & Run All
работает без браузера до 12 часов, но проверьте, что лог показывает URL.

## Вариант 2: Google Colab (запасной)

1. colab.research.google.com -> File -> Upload notebook -> Link/GitHub, или вставьте:
   `https://raw.githubusercontent.com/houlashdw/Iaa/main/cloud/colab_server.ipynb`
2. Runtime -> Change runtime type -> **T4 GPU**. Run all.
3. Скопируйте URL и ключ из последней ячейки.

**Предупреждение.** Условия бесплатного Colab могут ограничивать некоторые виды
использования (в частности удалённый доступ/туннели и раздачу сервисов), GPU не
гарантируется, сессия завершается при простое и через несколько часов. Перед
использованием **сами проверьте актуальные условия Google Colab**. Если сомневаетесь,
используйте Kaggle. На Colab одна GPU, поэтому модели чата и картинок меняются
местами автоматически (переключение занимает несколько секунд-полминуты).

## Контракт API (для приложения)

Все запросы, кроме `/health`, с заголовком `Authorization: Bearer <API KEY>`.

**Чат** `POST {URL}/v1/chat/completions`

```json
{
  "model": "qwen3-vl",
  "stream": true,
  "max_tokens": 1024,
  "temperature": 0.7,
  "messages": [
    {"role": "system", "content": "..."},
    {"role": "user", "content": [
      {"type": "text", "text": "Что на фото?"},
      {"type": "image_url", "image_url": {"url": "data:image/jpeg;base64,/9j/4AAQ..."}}
    ]}
  ]
}
```

Поле `model` игнорируется. Картинки лучше уменьшить до ~1024 px по длинной стороне.
Ответ при `stream:true` – SSE (`Content-Type: text/event-stream`): строки
`data: {"choices":[{"delta":{"content":"..."}}], ...}` и в конце `data: [DONE]`.
При ошибке внутри потока приходит `data: {"error":{"message":"..."}}` и `data: [DONE]`.
При `stream:false` – обычный JSON OpenAI (`choices[0].message.content`).

**Картинки** `POST {URL}/v1/images/generations`

```json
{"prompt": "...", "negative_prompt": "...", "width": 1024, "height": 1024,
 "steps": 25, "guidance": 6.0, "seed": -1}
```

`seed` = -1 – случайный. Ответ: `{"created":..., "data":[{"b64_json":"<PNG base64>","seed":123}], "width":1024, "height":1024}`.
Размеры округляются до кратных 8, максимум ~1536x1536 по площади. Необязательное поле `n` (1-4).
Ограничение SDXL: промпт длиннее ~77 токенов обрезается.

`GET {URL}/health` – без ключа, `{"status":"ok","gpu_state":"chat|image|idle",...}`.
Ошибки: JSON `{"error":{"message":"..."}}`, 401 при неверном ключе.

## Ориентировочные скорости (ОЦЕНКИ, не измерения)

- Чат 8B Q4_K_M на T4: ~15-25 токенов/с; 4B: ~30-45 токенов/с. Разбор картинки добавляет 1-5 с.
- Первый запрос после старта/переключения: +20-60 с на загрузку модели.
- SDXL 1024x1024, 25 шагов на T4: ~25-45 с; 768x768: ~15-25 с.
- На двух GPU (Kaggle T4 x2) обе модели держатся в памяти одновременно, переключения нет.
  На одной GPU (P100, Colab) модели меняются местами автоматически.

## Стоимость

Бесплатно в пределах квоты Kaggle (~30 ч GPU/неделю). Приложение и туннель Cloudflare тоже бесплатны.

## Когда квота закончилась

Арендуйте GPU по часам (RunPod, Vast.ai и т.п., 16-24 ГБ VRAM, ~0.2-0.5 USD/ч, цены уточняйте).
На арендованной машине (Linux + CUDA + Python 3.10+):

```bash
git clone https://github.com/houlashdw/Iaa && cd Iaa/cloud
pip install -r requirements.txt
# собрать llama-server (CUDA) и скачать модели так же, как в ноутбуке (ячейки 2-3)
export API_KEY="придумайте-длинный-пароль"
export LLAMA_SERVER_BIN=/путь/к/llama.cpp/build/bin/llama-server
export CHAT_MODEL=/путь/к/Qwen3-VL-8B-...Q4_K_M.gguf
export CHAT_MMPROJ=/путь/к/...mmproj-Q8_0.gguf
python server.py   # слушает порт 8000
```

Дальше либо откройте порт 8000 у провайдера, либо запустите туннель:
`cloudflared tunnel --url http://127.0.0.1:8000`. Используйте HTTPS-туннель, не голый HTTP.
Переменные: `GPU_MODE=swap|split`, `IMAGE_MODEL`, `CHAT_CTX`, `PORT` (см. начало `server.py`).

## Приватность

Промпты, фотографии и ответы идут с телефона через туннель Cloudflare (или ngrok) на
сервер Kaggle/Colab. Туннель использует HTTPS, но оператор туннеля технически может
видеть трафик, а провайдер облака – содержимое машины. Не отправляйте ничего, что не готовы
доверить этим сервисам. API-ключ не публикуйте: любой, у кого есть URL и ключ, пользуется вашей квотой.
Помните и об условиях использования Kaggle/Colab.
