# Neon 3D — девушка-волчица в поп-арт петле

3D-версия [`../neon`](../neon): та же 15-секундная петля (4 сцены, 128 BPM), но персонаж теперь настоящая 3D-модель на Three.js.
Все модели **процедурные** — никаких внешних файлов, текстур и ассетов, всё строится кодом.

Открой `index.html` в браузере (двойной клик, файл самодостаточный, Three.js вшит внутрь).

## Что изменилось по сравнению с 2D-версией

| | 2D (`neon`) | 3D (`neon3d`) |
|---|---|---|
| Пропорции | чиби | взрослые, ≈ 7 голов |
| Образ | короткое платье, чулки | закрытый: высокий воротник, длинные рукава, юбка ниже колена, плотные колготки, ботинки |
| Рендер | Canvas 2D | Three.js, toon-шейдинг + контур (inverted hull), камера с орбитой и крупным планом |
| Движение | кривые на плоскости | скелет, IK рук и ног, пальцы, ноги стоят на земле |
| Волосы/хвост | цепочки | ~50 лентовых прядей и хвост на Verlet-физике с коллизиями о плечи/грудь/голову |
| Лицо | рисунок | текстура лица, перерисовывается на лету (моргание, подмигивание, зрачки следят за курсором) |

Поп-фоны, сердечки, ноты, «?!», переходы-«ступеньки», зерно — те же 2D-слои, что и в `neon`: фон рисуется **под** 3D-персонажем, оверлеи **поверх**.

## Управление

`Space` — пауза · `M` — музыка (chiptune, по умолчанию выключена) · `F` — на весь экран · мышь/палец — она следит взглядом и поворачивает голову · клик — сердечки.

## Сборка

Исходники в `src/`, `index.html` собирается из них (esbuild бандлит Three.js в один файл):

```bash
cd neon3d
npm install
npm run build      # → index.html
```

| Файл | Что внутри |
|---|---|
| `src/character.js` | модель: торс-лофт, голова, волосы-пряди, уши, хвост, юбка, руки/ноги, физика |
| `src/face.js` | текстура лица (глаза, брови, рот, румянец) |
| `src/anim.js` | таймлайн сцен: позы рук/ног, мимика, камера |
| `src/pop2d.js` | 2D-фоны, частицы, переходы, зерно |
| `src/util.js` | toon-материал, контуры, ленты, лофт, IK, цепочки Верле |
| `src/main.js` | сборка слоёв, цикл, управление, адаптивное качество |

Параметры URL: `?q=1` — фиксированное разрешение (множитель к 1280×720), `?manual` — без автозапуска; покадровый рендер: `NEON.advanceTo(t)`.

## Ограничения

- Модель процедурная, поэтому по детализации не равна ручной 3D-модели (VRM/MMD): нет блендшейпов, лицо — текстурное, одежда без швов.
- Проверялось только в Chromium без GPU (SwiftShader). На обычном GPU нагрузка небольшая (≈ 250 draw-calls, 69 тыс. треугольников, ≈ 2 мс CPU на шаг физики), при тяжёлых кадрах разрешение снижается автоматически.
